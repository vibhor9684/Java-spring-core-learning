# First daily Java project

Use this standalone Maven project for today's lecture code. Add classes under `src/main/java` and tests under `src/test/java`.

Run it from the repository root:

```powershell
.\mvnw.cmd -f daily-learning\2026\2026-10-24-first-project\pom.xml test
```

To start a project for another day, copy this folder and rename it using `YYYY-MM-DD-topic`.
